Solved equations

Reaction delay adds distance without changing the braking time. Initial velocity affects the braking distance quadratically.

Phase 1 · reaction
a = 0; v = v0 = 20.0 m/s
dr = v0tr = (20.0)(0.75) = 15.0 m
Phase 2 · braking
a = −5.0 m/s²; 0 = v0² + 2a db
db = v0²/(2|a|) = 20.0²/[2(5.0)] = 40.0 m
Combine the phases
tstop = tr + v0/|a| = 4.75 s
dstop = v0tr + v0²/(2|a|) = 55.0 m

Geometric derivation of stopping distance

1. Delay phase: rectangle

base = tr = 0.75 s
height = v0 = 20.0 m/s
xr = Arectangle = base × height
xr = v0tr = (20.0)(0.75) = 15.0 m

2. Braking phase: triangle

base = tb = ttotal − tr = v0/|a| = 4.00 s
height = v0 = 20.0 m/s
xb = Atriangle = ½(base)(height)
xb = ½(v0/|a|)v0 = v0²/(2|a|) = 40.0 m

3. Equation of the braking line

m = Δv/Δt = (0 − v0)/(v0/|a|) = −|a|
v(t) − v0 = −|a|(t − tr)
v(t) = −|a|t + (v0 + |a|tr)
tr ≤ t ≤ ttotal
v(t) = −(5.00)t + 23.75
v-axis intercept: v(0) = v0 + |a|tr = 23.75 m/s

The dashed projection is not an extra phase of motion. It exposes the intercept of the same straight braking line.

4. Add the two areas

xtotal = xr + xb
xtotal = v0tr + v0²/(2|a|)
xtotal = 15.0 + 40.0 = 55.0 m

AP Physics 1 Kinematics Problem Family Guide

Core kinematics problem families

TypeRecognition cluesBasic approach
1. Definitions, averages, and signsDistance versus displacement; speed versus velocity; average versus instantaneous; “which direction?”Choose a positive direction first. Calculate displacement from xf−xi; use total path length only for distance.
2. Constant-velocity motion“Constant speed,” a=0, or distance and travel time are givenUse xf=xi+vt. The position graph is linear; velocity is constant.
3. Constant acceleration with timea and t are given; asks for position or velocity after a stated intervalUse vf=vi+at and/or Δx=vit+½at².
4. Endpoint condition with no timeTime is absent; asks for stopping distance, final speed, or speed after a displacementUse vf²=vi²+2aΔx. This is the “eliminate time” family.
5. Turnaround or return motion“Momentarily stops,” “reverses direction,” “returns to its starting point”At a turnaround, set v=0. At return to the starting point, set Δx=0. These are different events.
6. Free fall and vertical launchesDropped, thrown upward/downward, maximum height, time to hit the groundTreat it as constant acceleration with ay=−g if upward is positive. At maximum height, vy=0, but ay≠0.
7. Threshold or decision problems“Minimum,” “maximum,” “just barely,” “safe,” “before the light changes,” “will it clear?”First solve the boundary case using equality—stops exactly at the line, arrives exactly at the deadline—then compare the actual result with that threshold.
8. Multistage or piecewise motionReaction then braking; accelerate–cruise–brake; delayed start; acceleration changesDivide the story into stages. The final x, v, and t of one stage become the initial conditions of the next. Add displacements and elapsed times.
9. Two-object meeting or chase problemsMeet, collide, catch, overtake, arrive simultaneously; trains approaching each otherWrite a separate position equation for each object using one coordinate system and one clock. At the event, set xA(t)=xB(t).
10. Relative-motion problems“As observed from,” “relative to,” a moving platform, one car appearing to move backwardUse v⃗A/B=v⃗A/G−v⃗B/G. This concerns perceived velocity, not necessarily where two objects meet.
11. Two-dimensional projectile motionLaunched horizontally or at an angle; range, height, flight time, landing velocitySplit into independent axes: ax=0 and ay=−g. The horizontal and vertical motions share the same time.

The disguises AP tests use

Any one of those physical problem families can appear in several different forms:

  • Numerical calculation: Find a specific time, velocity, or displacement.
  • Symbolic derivation: Produce an expression without substituting numbers.
  • Graph translation: Convert among x(t), v(t), a(t), a motion diagram, and a written description.
  • Comparison/scaling: Predict what happens if speed, acceleration, height, or time is doubled.
  • Experimental/data problem: Determine motion from a table, video, graph, or proposed experiment.
  • Claim and justification: Decide which prediction is correct and explain using signs, slopes, areas, or an equation.

That last layer matters because the current AP framework expressly emphasizes translating among equations, graphs, diagrams, tables, and verbal descriptions—not merely selecting a kinematic equation. Unit 1 also explicitly includes relative motion and two-dimensional motion. Current College Board AP Physics 1 description

A universal recognition routine

Before using an equation, she should write:

  1. What object or objects are moving?
  2. Is this one stage or multiple stages?
  3. What event defines the requested moment?
    Examples: v=0, xA=xB, xf=xi, or the object reaches a boundary.
  4. Is acceleration constant during this stage?
  5. Which variable is missing from the problem?
    Select the equation that does not contain that variable.
  6. Do the signs and units make physical sense?
