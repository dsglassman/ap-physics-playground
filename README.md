# AP Physics Playground

An interactive collection of AP Physics 1 learning modules, beginning with the Kinematics Motion Trainer.

## Current module

- **Kinematics Motion Trainer** — connect position, velocity, and acceleration through synchronized animation, graphs, tables, and themed environments.

## Open the site

https://dsglassman.github.io/ap-physics-playground/

## Project status

This is a development-year project for teachers and a small group of students. Additional modules—energy, momentum, electricity and magnetism, and others—will be added after they have been refined.

Some development themes use recognizable visual references. Those assets and references must be reviewed, licensed, or replaced before a broad public release.
